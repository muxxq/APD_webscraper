# Tema Proiectului: Web Scraper

- **Topicul:** Web Scraping pe multiple magazine online (ex. eMAG, Altex) pentru compararea prețurilor la diferite categorii de produse (Proiect de tip *Application Oriented*).
- **Limbaj de programare:** Python 3.11+
- **Sisteme / Framework-uri folosite:**
  - Funcționalitate Web: `requests`, `aiohttp`, `httpx`, `BeautifulSoup4`, `lxml`
  - Paralelizare (APD): `concurrent.futures`, `multiprocessing`, `asyncio`
  - Date & Metrici: `pandas`, `openpyxl`, `matplotlib`, `psutil`
